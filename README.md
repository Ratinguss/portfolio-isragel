## 🚀 Deployment

This site is automatically deployed to [GitHub Pages](https://pages.github.com/) whenever changes are pushed to the `main` branch.

### Enable GitHub Pages (first-time setup)

1. Go to your repository on GitHub: `https://github.com/Ratinguss/portfolio-isragel`
2. Click **Settings** → **Pages** (in the sidebar)
3. Under **Source**, select **GitHub Actions**
4. Push a change to the `main` branch (or manually trigger the workflow from the **Actions** tab)
5. After the workflow completes, your site will be live at `https://ratinguss.github.io/portfolio-isragel/`

## 🛠️ Local Preview

To preview the site locally, open `index.html` in your browser or use a local server:

```bash
# Using Python
python3 -m http.server 8000

# Using Node.js (npx)
npx serve .
```

Then open `http://localhost:8000` in your browser.
