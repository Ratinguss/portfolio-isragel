# Isragel's Portfolio

A modern, responsive portfolio website built with React, Vite, and Tailwind CSS.

## 🚀 Features

- **Modern UI Design**: Clean and professional design with gradient accents
- **Fully Responsive**: Works seamlessly on desktop, tablet, and mobile devices
- **Smooth Animations**: Elegant transitions and scroll animations
- **Multiple Sections**:
  - Hero section with introduction and CTAs
  - About section with statistics
  - Skills showcase with categorized technologies
  - Featured projects with descriptions
  - Contact form with social links
- **Fast Performance**: Built with Vite for optimal load times
- **Tailwind CSS**: Utility-first styling for easy customization

## 🛠️ Technologies Used

- **React 19**: Modern UI library
- **Vite**: Next-generation frontend tooling
- **Tailwind CSS 3**: Utility-first CSS framework
- **JavaScript (ES6+)**: Modern JavaScript features

## 📦 Installation

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## 🎨 Customization

To customize the portfolio for your own use:

1. **Personal Information**: Update the Hero component with your name and description
2. **About Section**: Modify the stats and journey text in the About component
3. **Skills**: Update the skills array in the Skills component with your technologies
4. **Projects**: Replace the projects array in the Projects component with your own work
5. **Contact**: Update email and social links in the Contact component
6. **Styling**: Modify `tailwind.config.js` to change colors and themes
